Macro Dashboard

India's Economic Pulse

A macroeconomic indicator dashboard tracking GDP, inflation, fiscal deficit, trade, and sectoral composition.

ExcelPower BIMacroeconomics
Timeline
September 2024
Tools
Excel, Power BI, MOSPI, RBI
Type
Macro Dashboard

The question

Can a single readable dashboard help non-economists track India’s macro health without drowning in jargon?

Data used

Public indicators from MOSPI, RBI, and related government statistical releases.

Methodology

Curate a small set of high-signal indicators, normalize time ranges, and prioritize interpretability over chart count.

Key findings

Readers engage more when each indicator has a one-line “why it matters” note than when offered a dense wall of charts.

Outputs

Static and presentation-friendly macro visuals suitable for policy and classroom contexts.
