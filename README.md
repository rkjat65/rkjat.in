## Featured Projects

**[GyanGram](https://rkjat.in/portfolio/gyangram.html)** — Flutter-based UPSC prep app. Solo-built as a non-coder product owner using AI-augmented development (Cursor, Claude Code). 108+ cards, interactive markdown articles, 4-tab architecture.

**[IPL Analytics Platform](https://github.com/rkjat65/ipl-analytics_new)** — End-to-end IPL analysis. 17 seasons · 1,169+ matches · DuckDB + FastAPI + React.

**[India's Fiscal Federalism](https://rkjat.in/portfolio/fiscal-federalism.html)** — Interactive visualization of ₹111 lakh crore centre-state financial flows across 28 states.

**[India Economic Pulse](https://github.com/rkjat65/India-Economic-Pulse)** — Macroeconomic indicator dashboard tracking 8 key indicators from 2012–2025.
