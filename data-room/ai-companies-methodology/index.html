AI Companies Dataset Methodology

How indices were constructed, what was excluded, and how to reproduce the charts in the companion story.

1 June 2026

Scope

The dataset includes ten companies chosen to represent four archetypes:

  1. Foundation model labs (OpenAI, Anthropic, xAI, Mistral AI)
  2. Big-tech AI groups (Google DeepMind, Microsoft AI, Meta AI)
  3. Enterprise-focused vendors (Cohere)
  4. Infrastructure (Nvidia AI)

Stability AI is included as an open-model lab case study.

Index construction

Indices (0-100) are relative scores for storytelling clarity, not official market shares:

  • API adoption index weights public API availability, developer documentation quality, and ecosystem mentions in open-source repositories.
  • Research impact index weights benchmark leadership (MMLU, coding, multimodal) and widely cited technical reports.
  • Compute spend index is normalized to the highest spender in the sample (OpenAI/Nvidia = 100).
  • Enterprise deals index proxies large-contract penetration based on public partnership announcements.

Exclusions

  • Private financials without credible public estimates are recorded as 0 with notes in the story body.
  • Chip foundries, cloud regions, and sub-vendor contracts are not double-counted.
  • India-specific AI startups are out of scope for this global snapshot (future installment).

Reproducibility

  1. Download the JSON snapshot.
  2. Charts in the story use Observable Plot via site BarChart and ScatterChart components.
  3. To extend the dataset, append rows in CSV and rebuild the site (npm run build).
